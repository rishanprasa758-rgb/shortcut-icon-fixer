# 快捷方式图标修复器

桌面 / 开始菜单 / 任务栏里图标变成白纸时，用它一键扫描并修复。

## 怎么用

双击 `ShortcutIconFixer.exe`，打开后自动扫描，**只显示有问题的项**：

1. 红色「图标源丢失」的项目默认已勾选
2. 点「一键修复 (N)」
3. 修完看日志；桌面按 F5 刷新

想核对全部 200 多个快捷方式时，点右上角「显示全部 (N)」，再点「只看问题」切回来。

任务栏上的图标**不会自动变**——要右键取消固定，再重新固定一次。

## 状态说明

| 状态 | 意思 | 能修吗 |
|---|---|---|
| 正常 | 图标源存在 | — |
| 图标源丢失 | 图标文件没了，但程序还在 | ✅ |
| 目标不存在 | 程序本身已卸载/移动 | ❌ 建议删掉快捷方式 |
| 无本地图标源 | 网页快捷方式，没有本地图标 | ❌ |
| 系统项，跳过 | UWP / 特殊项，读不到目标 | ❌ |

## 它做了什么

- **Steam 游戏**：从游戏 exe 里把图标抠出来；exe 里没有就用 Steam 缓存封面生成
- **普通程序**：把快捷方式的图标改指它自己的 exe
- 改之前都会备份到 `%LOCALAPPDATA%\ShortcutIconFixer\backup\<时间>\`，保留最近 5 次
- 没有权限写原位置时，自动把图标放到 `%LOCALAPPDATA%\ShortcutIconFixer\icons\`

「重建图标缓存」是独立按钮，会重启资源管理器，只在修复后仍显示白纸时才用。

公共开始菜单里的项目在 `C:\ProgramData` 下，普通权限改不了。修复失败时点
**「管理员重试」**，Windows 会弹一次 UAC，之后就能改。

## 命令行（可选）

> 需要通过 Python 源码运行。打包后的 exe 是窗口程序，没有控制台，命令行输出看不到。

```bash
python app.py --scan            # 列出所有有问题的快捷方式
python app.py --scan --json     # 机器可读输出
python app.py --fix --dry-run   # 只演练，不改文件
python app.py --fix             # 直接修
```

## 自己重新打包

双击 `build.bat`，产物是 `dist\ShortcutIconFixer\` **整个文件夹**（exe + `_internal`）。
分发时把整个文件夹打包，不能只拿 exe——单文件模式会往 `%TEMP%` 解压，容易被杀软删掉运行库。
首次运行未签名 exe 可能弹 SmartScreen，点「更多信息 → 仍要运行」。

## 已知限制

- 程序已卸载的快捷方式没法凭空造图标
- Steam 更新后可能又删掉 `.ico`，再跑一次即可
- 杀毒软件可能对 PyInstaller 打包的 exe 敏感（已加 `--noupx` 降低误报）
